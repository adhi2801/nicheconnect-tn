# Prototypes

Design prototypes, kept here for reference. They are single HTML files with sample data and no backend. Open them in a browser.

| File | What it is | Published copy |
|---|---|---|
| `dashboard.html` | Brand and creator dashboard (use the Brand view / Creator view switch). Black and butter yellow on cream: the look every surface now follows (`tokens/tokens.json`). | https://claude.ai/artifact/MniAhS5AMPgAhFtZvEDa7F |
| `homepage.html` | Marketing homepage with the 3D temple scene. Heritage burgundy and gold, which still has to be restyled to the one theme. | https://claude.ai/artifact/JDpfAfKdxJ65GPrL55hS4p |

These are not production code. They use fonts from Google Fonts and the homepage loads its 3D scene inline. The real apps are `apps/web` (Next.js) and `apps/mobile` (Flutter).
